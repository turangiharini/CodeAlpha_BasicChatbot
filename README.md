# Basic Chatbot 🤖

## Overview
This project is a simple rule‑based chatbot built in Python. It simulates conversation by matching user inputs with predefined responses, demonstrating how computers can mimic human dialogue in a structured way.

## Features
- Responds to specific inputs like "hello", "how are you", and "bye".
- Uses conditional statements (`if-elif-else`) for decision making.
- Runs in a loop for continuous interaction until the user exits.
- Organized with functions for clarity and reusability.

## How to Run
1. Save the program as `chatbot.py`.
2. Run it in your Python environment (`python chatbot.py`).
3. Type a message when prompted and receive a response.
4. Type `bye` to end the conversation.
